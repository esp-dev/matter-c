## Artifacts and independent checks

- The existing C payload function produces the QR text. The same vendored C
  qrcodegen encoder and version4 ceiling, medium ECC, automatic mask, boost and
  four-module quiet zone used by the desktop produce a headless bitmap.
- zxing-cpp **2.3.0** independently scans that bitmap. The decoded payload equals
  the C text; a blank image is rejected. The scan supplies TH's QR input.
- Unmodified chip-tool parses all seven relevant fields and independently
  generates an identical QR payload. Version, rendezvous, discriminator,
  passcode, VID/PID and commissioning flow match the development fixture.

  the scanned QR, and CM reports an open basic commissioning window. TH's
  discriminator prompt uses this captured field, not the QR's decoded value.
- CHIP generates an 11-digit laboratory setup card for the same passcode and
  discriminator. Its parsed short discriminator/passcode match; a changed check
  digit is rejected. This card supplies TH's manual-code input.
- The isolated node stops cleanly, with empty stderr.

The existing C payload self-test also passes under Memcheck with zero errors

## Reproduction

Build the existing payload utility from `test_gui_pairing.c` and
`matter_gui_pairing.c`, and compile `third_party/qrcodegen/qrcodegen.c` as a shared
library. Use an isolated Python environment with Pillow and zxing-cpp2.3.0:

```sh
python tools/matter/tests/test_onboarding_payload_chip.py \
  --payload-exe /path/to/payload --qr-library /path/to/qrcodegen.so \
  --node /path/to/matter-node --chip-tool /path/to/chip-tool \
  --credentials /path/to/development-credentials --interface 2 \
  --output /path/to/fresh-private-evidence
valgrind --error-exitcode=99 --leak-check=full --show-leak-kinds=all \
  --track-origins=yes /path/to/payload
python -m py_compile tools/matter/tests/test_onboarding_payload_chip.py
python tools/matter/check_test_map.py
git diff --check
```

The original TH run uses only the OnboardingPayloadTestSuite entries
TC-DD-1.1/1.2 and a bounded 180-second external execution envelope. It does not
edit the original test sources or bypass their assertions. See the
[machine-readable record](csa31-results.json).
